Prototype limitations and diagnostics

Other LaTeX projects use full builds with selectable text but no source navigation. Fast incremental compilation and token navigation support the supplied corpus and a documented LaTeX subset. Windows compilation currently runs through WSL. Timing includes the measured pipeline and display scheduling, not a claim of meeting 150 ms.
